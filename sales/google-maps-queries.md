# 🔍 Google Maps Target Hunting — Tezpur/Rangapara

## Method (Har Category Ke Liye Same)

1. Google Maps kholo → search query type karo (neeche di hui)
2. Result list scroll karo
3. **Filter:** jinke pas "Website" button NAHI hai → ⭐ TARGET
4. Phone number + business name copy karo → `leads.csv` mein paste
