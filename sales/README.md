# 💼 Sales Playbook — Tezpur/Rangapara Local Outreach

Ye folder tumhare freelance web dev sales operation ka **command center** hai.

## 📂 Files Overview

| File | Use |
|---|---|
| `google-maps-queries.md` | Step-by-step kaise targets dhundhne hain |
| `leads.csv` | Tracker — sab prospects yahan log karo |
| `pitch-templates.md` | WhatsApp/call pitches (copy-paste ready) |
| `pricing.md` | Package tiers + objection handling |

## 🎯 Aaj Ka Goal

**1 paying client lock karna.** Realistic conversion: 20 outreach → 3-5 interested → 1 close.

## ⚡ Quick Start (2 hours)

1. **`google-maps-queries.md` kholo** → 30 min mein 20 leads nikal lo, `leads.csv` mein log karo
2. **`pitch-templates.md`** se WhatsApp message copy karo, har lead ko personalize karke bhejo
3. **Demo URL** ke saath bhejo (deploy hone ke baad)
4. **Reply aane par** → `pricing.md` se package quote karo
5. **Half advance UPI lo** → kaam shuru

## 📊 Daily Targets

| Stage | Target |
|---|---|
| Outreach (WhatsApp + call) | 20-30/day |
| Demo views | 8-12/day |
| Interested replies | 3-5/day |
| Closed deals | 1-2/week (start), 3-5/week (after 2 weeks) |

## 💰 Revenue Math

- Avg ticket: ₹6,000
- 3 clients/month = ₹18,000
- 5 clients/month = ₹30,000
- 10 clients/month = ₹60,000

Tier-3 town mein 5 clients/month achievable hai 2-3 months ke baad.
